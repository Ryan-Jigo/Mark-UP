# Mark-UP

A modern Markdown editor and documentation tool designed to make writing, editing, and previewing Markdown content simple and efficient.

## ✨ Features

- Live Markdown preview
- Clean and intuitive user interface
- GitHub Flavored Markdown support
- Fast and responsive editing experience
- Export and sharing capabilities
- Cross-platform compatibility

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js (v18 or later)
- npm or yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/Ryan-Jigo/Mark-UP.git
cd Mark-UP
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🛠️ Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
